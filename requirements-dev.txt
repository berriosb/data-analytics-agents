# requirements-dev.txt — shortcut a `pip install -e .[dev]`.
#
# Las dependencias del toolkit viven en `pyproject.toml` (extras:
# dev / excel / sql / cloud / viz / api). Este archivo existe por dos
# razones:
#
#   1. Compatibilidad con CI y scripts que ya hacen
#      `pip install -r requirements-dev.txt` sin saber del pyproject.
#   2. Documentación rápida: si querés ver qué corre `make test-unit`,
#      mirá este archivo.
#
# Flujo recomendado (cualquiera de los dos es equivalente):
#
#     pip install -e .[dev]
#     # o
#     pip install -r requirements-dev.txt
#
# Para deps adicionales por dominio de skill:
#
#     pip install -e .[excel]   # excel-profiler + excel-formulas
#     pip install -e .[cloud]   # drivers Snowflake / BQ / Redshift / Databricks
#     pip install -e .[viz]     # report-export (PDF / PPTX / HTML)
#     pip install -e .[api]     # api-builder (FastAPI)
#     pip install -e .[all]     # todo lo anterior
#
# No publicar a PyPI: este toolkit se distribuye vía npm.
